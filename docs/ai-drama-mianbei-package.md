## 一、30集完整剧本大纲

**一句话卖点**：人人都以为他是最惨的猪仔，直到园区大佬开始喊他"爷"。

### 第1幕 被骗入局（1–3集）——立落差
1. **《铁门》**：冷开场，程烨被押进园区，猪仔剃头戴镣铐。洋哥立威，坤叔放话"进得来出不去"。程烨装怂自称"炊事兵"，主动替人顶下话务组差事。钩子：他一路在记哨塔、电网、配电箱位置。
2. **《体检》**：闪回骗局全程——妹妹病重欠债、中介"月薪八万境外客服"、边境收证件、铁门合拢。白天"体检"，实为评估谁适合"卖器官"。程烨在排队名单上看到阿凯的名字。
3. **《第一课》**：话务组长逼新人背诈骗话术。程烨夜探被洋哥抓个正着，洋哥当众要打——程烨压制住本能，挨了一棍装死。镜头捕捉他瞬间的杀意，洋哥莫名一寒。

### 第2幕 蛰伏摸底（4–8集）——扮猪吃虎
4. **《医务室》**：程烨装病摸到医务室（园区唯一有地图/药品的地方），暗中记下监控室、发电机房。顺手救下险些被卖的阿凯，对外说"他是我的业绩工具"。
5. **《组长》**：程烨"超额完成业绩"当上话务组长，借机换到能走动的账房岗位，接近坤叔核心资料。
6. **《隔壁的声音》**：程烨发现隔壁是被控制的女主播团队，领头的小雨偷偷藏手机、录证据。两人第一次试探性互认。
7. **《考验》**：洋哥始终疑他，设局让他亲手"处置"逃跑猪仔。程烨表面下狠手，实则偷天换日把人藏进地窖，惊险过关。
8. **《坤叔的办公室》**：程烨被调进核心层当贴身。第一次看到柜里的被拐名单和"业绩账本"——他意识到自己握住了整条链的证据。

### 第3幕 反间上位（9–14集）——连续打脸
9. **《替罪羊》**：阿凯留证差点暴露，程烨当众演戏甩锅给一个已死的替罪羊，园子里人心开始向他聚拢。
10. **《妹妹的电话》**：上家拿妹妹威胁程烨"做一单大的"，程烨假意配合，实则把这场胁迫变成接近大老板的机会。
11. **《瘦猴》**：策反第一个打手瘦猴（他曾救过对方），拿到夜巡路线和交班表。
12. **《摊牌》**：反转——阿凯不是普通IT男，是警方技术卧底。两个卧底（程烨为线人）在厕所烟头点火对暗号合流。
13. **《小雨的身世》**：小雨的哥哥也是被卖失踪的人，她进园区是为了找他。三条线正式合并。
14. **《离间》**：园区泄密惊动上家，要求彻查。程烨顺水推舟，把嫌疑引给洋哥——坤叔与洋哥反目，**第一波内讧大爽点**。

### 第4幕 爆发逃亡（15–25集）——燃点密集
15. **《失势》**：坤叔削洋哥的权，洋哥恨上程烨，扬言要弄死他（埋个人恩怨）。
16. **《B计划》**：程烨借话务组长身份，组织猪仔骨干，制定"断电+暴动+剪网"大逃亡计划。
17. **《检查》**：上家派人突击查业绩，程烨全程陪笑周旋，刀尖上跳舞。
18. **《叛徒》**：骨干里有人被洋哥收买告密。程烨当众自证、反杀叛徒，建立绝对威信。
19. **《举报》**：女主播团队有人举报小雨藏手机，程烨舍身相救。两人感情线确立——不是恋爱脑，是生死信任。
20. **《提前转移》**：坤叔突宣布转移一批猪仔（去向更黑）。时间窗口被压缩，计划被迫提前。
21. **《摊牌》**：程烨为保人质当众掀桌，一人镇全场——**全剧最高光瞬间**。坤叔这才惊觉：他不是猪仔。
22. **《火并》**：园区第一波交火，洋哥与程烨正面对决，个人恩怨清算。
23. **《断电》**：暴动开始，断电剪网，猪仔外逃；阿凯黑掉监控，小雨带女主播团队冲出。
24. **《山林》**：缅北雨林夜逃，坤叔纠集上家武装围堵。骨干大壮为掩护众人牺牲。
25. **《至暗》**：断桥埋伏，血战突围。程烨爆发复仇，情感燃点推至顶峰。

### 第5幕 收网清算（26–30集）——正义落点
26. **《援军》**：警方边境联合行动队到位（阿凯/程烨坐标），武装对峙。
27. **《清算》**：坤叔挟小雨当人质，程烨设局反杀——**头号反派落幕，最爽一集**。
28. **《将军》**：幕后大老板现形，跨境收网，整园名单全获救。
29. **《回家》**：受害者与家属团圆蒙太奇，妹妹手术成功，程烨真实身份公开。
30. **《种子》**：尾声温馨收束 + 彩蛋：程烨收到加密短信——"他们换了个地方"。**第2季钩子**。

## 二、角色定妆提示词与一致性方案

> ⚠️ **AI短剧第一坑 = 同一角色每集长得不一样。** 解法：先把每个角色按下面提示词生成一张满意的定妆图并**收藏存档**，之后所有镜头都用它**垫图（参考图）**生成，别裸写新提示词。一张定妆可顺手多生成几个角度（正脸/侧脸/全身/不同表情），存成"角色文件夹"。

**通用风格后缀（每个提示词拼上这句）：**
> 电影级写实剧照，真实皮肤质感，冷青橙暗色调，硬朗侧光，景深虚化，竖屏9:16构图，细节丰富，8k

**通用负面词（固定复制）：**
> 卡通，动漫，插画，畸形，多余手指，崩脸，面部扭曲，模糊，低清，水印，文字，字幕

### 角色定妆提示词
- **① 程烨（主角·退役军人）**：28岁中国男性，板寸短发，左眉一道旧疤，下颌线硬朗，眼神平静却透着冷，穿一件洗旧的黑色T恤和深灰工装裤，右手虎口有老茧，站在灰暗的水泥墙前，压抑隐忍的表情 + 通用后缀
- **② 坤叔（大反派·笑面虎）**：55岁华人男性，油亮背头鬓角微白，金丝眼镜，微胖，穿暗色中山装，手腕金表，皮带勒出肚腩，坐在皮椅上嘴角带笑但眼神阴冷，像只笑里藏刀的老狐狸 + 通用后缀
- **③ 洋哥（打手·狠角）**：32岁男性，光头，壮硕，脖子一道旧疤，花臂纹身，黑色背心，粗金链，凶狠瞪眼，手持铁棍站在冷光灯下 + 通用后缀
- **④ 小雨（女主播·内应）**：24岁中国女性，低马尾，素净圆框眼镜，浅色衬衫，气质文气却眼神坚毅，抿着嘴，像是藏着心事，站在主播间的柔光灯下，带一点疲惫 + 通用后缀
- **⑤ 阿凯（IT工程师·技术卧底）**：26岁男性，微胖，黑框眼镜，格子衬衫，双肩包，满脸稚气带着紧张，下意识推眼镜，站在机房屏幕前 + 通用后缀

**生成顺序建议**：先出程烨、坤叔两张主角色定妆，满意后再补其余。

## 三、第1集完整脚本（约2分钟）

格式：场景 → [时间] 画面 / 台词 / 音效。旁白统一为程烨（VO）。

### S1 冷开场 · 铁门（00:00–00:20）
- **[00:00] 黑场。** SFX：沉重铁门"哐——"合拢的回音。
- **[00:02] 程烨VO（低沉平静）**："他们说，来缅北是发财的。"
- **[00:04] 内景 园区大厅。** 冷白日光灯，灰墙上用红漆刷着"努力·奋斗"——讽刺。一排被剃光头、戴脚镣的男人蹲在墙根。
- **[00:08] 洋哥**拎铁棍巡过，一脚踹翻新来的："抬头！看着我的脸！"
- **[00:12] 坤叔**缓步走入，金丝眼镜反着白光，微笑着接话："这扇门——进得来，出不去。"
- **[00:16] 特写**：蹲着的人群里，程烨缓缓抬眼。眼神很静。 **音乐：低频压迫感起。**
- **[00:20] 黑场，剧名砸出**：《被卖到缅北后，我把整个园区反杀了》+ 字幕"本故事纯属虚构，警惕境外高薪骗局"。

### S2 闪回 · 骗局（00:20–00:45）——调色转暖白，与园区冷调形成反差
- **[00:20] 内景 医院。** 妹妹躺在病床上戴着氧气面罩。程烨攥着缴费单，上面的数字清晰放大。
- **[00:26] 中介画外音（油腻热情）**："境外客服，包吃住，月薪八万！退伍兵优先——你这种，最抢手！"
- **[00:30] 外景 边境山路。** 破旧大巴颠簸，尘土漫天。程烨望向窗外，脸色沉默。
- **[00:36] 内景 检查站。** 两本证件被一只手收走。程烨手指动了动，终究没反抗。
- **[00:40] 铁门再次合拢"哐——"。** 闪回结束，画面转冷调，落回园区。

### S3 立规矩（00:45–01:35）——主冲突场
- **[00:45] 内景 园区办公室。** 新人们排成一排，一个接一个按手印签"卖身契"。
- **[00:50] 洋哥**："欠公司培训费的，自己想办法——卖器官，还是给坤爷当狗？"众人发抖。
- **[00:56] 阿凯（IT男）腿一软出声**："我、我不是来干这个的——你们这是诈骗！"
- **[01:00] 洋哥**一把揪起他按在桌上，抄起老虎钳："诈骗？老子先废你一根手指，当学费。" 特写：钳子一点点逼近。
- **[01:08] 人群里，一直低头的程烨抬起了眼。** 坤叔饶有兴致地抬手："慢。"
- **[01:14] 坤叔打量程烨**："我听说——你是侦察兵退役？" 全场安静。
- **[01:20] 程烨抬头，笑了笑，目光平静到诡异**："报告老板，我当的是炊事兵。颠勺的。"（观众已知他撒谎——他刚进大厅就在数看守、记门口位置）
- **[01:26] 坤叔眯眼笑**："炊事兵好。我这缺个给上头做饭的。"
- **[01:30] 程烨突然开口，声音不大**："老板——让我替他上工吧。我嘴皮子还行，保证超额完成业绩。" 屋内死寂。坤叔镜片反光，半晌："……行。给他个机会。"
- **[01:35] 洋哥阴沉地盯着程烨。** 程烨对洋哥哈腰一笑，被带出门时，回头朝呆住的阿凯轻轻点了下头。

### S4 结尾钩子（01:35–02:00）
- **[01:35] 走廊。** 程烨被押去话务组，脚步却异常稳。路过监控盲区的一瞬，他飞快扫过——窗外哨塔、围墙上电网、配电箱的位置。守卫毫无察觉。
- **[01:48] 程烨VO（重叠，冷）**："他们说我是猪仔。可猪仔——也能咬断养猪人的喉咙。"
- **[01:55] 黑场。** 字幕预告："第2集：第一通电话，他拨给了自己人……" **BGM戛然而止。**

### AI短剧分镜纪律（必守）
1. **别拍长镜头**——AI视频每段只稳2–5秒，按"每镜3秒"切，用剪辑节奏骗过AI僵硬感。
2. **口型对不上就别露正脸说话**——对白戏切"背身/侧脸/剪影/低头"，或用旁白覆盖；必须露脸说话的戏再做对口型工具。
3. **情绪靠光线和景别给**：压迫=顶光+俯拍；隐忍=特写+暗部；爆发=慢推+升格。
4. **转场用"动作衔接"**：门合拢、灯灭、甩镜，比AI生成转场更稳更省。
5. **同场景同机位素材拍足再换**，剪辑才有"正反打"素材可用。
6. **每集结尾必须留钩子**（预告下一集），竖屏短剧吃的是"追更率"，钩子决定完播率。

## 六、AI生产流水线与工具清单

```
写剧本/台词 → 逐镜分镜脚本表 → 角色定妆图(锁形象)
→ 文生图(垫图) → 图生视频 → 配音对白 → 音效+BGM → 卡点剪辑 → 字幕/封面 → 发布
```

| 环节 | 工具（国内推荐） | 说明 |
|---|---|---|
| 文生图 | 即梦AI / 豆包 / Midjourney | 出分镜图、定妆图，MJ英文提示词质量最高 |
| 文生视频/图生视频 | 可灵Kling / 即梦 / Vidu / Runway | 每段生成2–5秒，一次多生成几条挑最优 |
| 配音 | 剪映文本朗读 / 魔音工坊 / 克隆音色 | 程烨用低沉稳男声，坤叔用阴柔中年声 |
| 剪辑/字幕/卡点 | 剪映（全流程） | 竖屏9:16，踩点剪辑，自动字幕 |
| 发布 | 红果 / 抖音 / 快手 / 视频号 | 第一集免费引流，后续设付费/短剧分成 |

**人物一致性工作流（最重要）**：定妆图 → 建角色文件夹 → 每镜垫图 → 生完逐镜人眼检查，五官崩了立刻重抽，别等到剪辑才后悔。

**运营提示**：片头固定3秒内给冲突钩子，片尾固定"下集预告"钩子；评论区安排引导"第几集最燃"话题，吃平台自然推荐。
